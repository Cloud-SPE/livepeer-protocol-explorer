Add `CREATE INDEX … ON raw_protocol_events (chain_id, is_canonical, finality, block_timestamp) WHERE is_canonical = TRUE` (or rewrite the predicate to use a `block_timestamp` range comparison directly so the existing index can serve it). | S8.1, S7.2 | medium | Open.
